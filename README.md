# MOBA Target Lock System

> **Created by Antono** | 🇮🇩 Indonesia

A game development project featuring a target lock system for MOBA (Multiplayer Online Battle Arena) games.

## 🎮 About

This project implements a target lock system commonly found in MOBA games, allowing players to lock onto enemies during combat.

## ✨ Features

- 🎯 Smart target selection
- 🔄 Auto-lock and manual lock modes
- 📍 Target indicator display
- 🎮 Smooth camera transitions
- 🕹️ Keyboard and mouse controls
