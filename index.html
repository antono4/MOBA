Game Features

Berbagai fitur canggih untuk pengalaman MOBA terbaik

🎯

Smart Target Lock

Sistem penguncian target otomatis dengan prioritas HP terendah. Visual indicator real-time untuk gameplay yang lebih responsif.

⚔️

6 Role Classes

Berbagai pilihan role: Tank, Fighter, Assassin, Mage, Marksman, dan Support. Setiap role memiliki skill unique.

🗺️

3-Lane Map

Map dengan Top, Mid, dan Bottom lane. Jungle area dengan buff monsters dan 2 epic boss: Kurala Wyrm dan Void Sentinel.

🌐

Low Latency Netcode

Server authoritative dengan rollback netcode untuk pengalaman multiplayer yang adil dan minim lag.

💰

Balanced Economy

Sistem gold dan EXP yang transparan. Item progression yang meaningful dengan comeback mechanics.

🎨

Kurala Cyberpunk Theme

Visual theme unik yang menggabungkan cyberpunk dengan mitologi Nusantara. Aesthetic yang memukau!

About the Game

Built with Unity

C# Scripts

Documentation
